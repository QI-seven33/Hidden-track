## 待补录屏

实际游戏录屏尚未提供，不使用拼接截图、生成动画或模拟操作视频替代。收到后再接入并记录格式、时长及是否剪辑。

## 后续采集建议

建议采集 1440×900 或 1920×1080、浏览器缩放 100% 的画面；以完整保留网页布局为准，不为了凑尺寸裁掉手牌、线索或结算信息。

| 素材     | 内容                                               | 建议文件名              |
| -------- | -------------------------------------------------- | ----------------------- |
| 选歌     | 练习曲库、歌曲与专辑资料                           | `desktop-selection.png` |
| 事件选择 | 三选一事件与已选效果                               | `desktop-events.png`    |
| 牌桌     | 手牌、压力、线索、当前操作                         | `desktop-battle.png`    |
| 结算     | 实际胜负及歌曲揭幕                                 | `desktop-result.png`    |
| 录屏     | 从选歌到出牌、拿线索和结算的实际过程，可剪辑并标注 | `desktop-gameplay.mp4`  |

不要包含登录二维码、Cookie、密钥、带签名的播放链接或个人音乐库。录制前确认昵称与头像是否愿意公开；录屏中的第三方音乐和美术权利仍需按来源处理，首版可以提供无声录屏。

接入每份素材时记录版本/提交、分辨率、电脑网页环境、是否剪辑与采集时间。实际运行的测试环境截图应标明测试环境，不能当作当前真实账号流程已全部验收的证明。

小型 PNG 可放在本目录并在 README 中使用相对路径嵌入；视频可使用 GitHub 附件或 Releases，避免将过大的原始录屏直接放进 Git 历史。不上传旧客户端、私人截图目录或测试缓存。
